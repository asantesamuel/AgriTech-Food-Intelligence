ADRs record durable, cross-cutting decisions that constrain future implementation.
Feature behavior and ticket acceptance criteria belong in feature specifications
and Jira, not in ADRs.

## Lifecycle

- **Proposed:** Under cross-functional review.
- **Accepted:** Approved and expected to guide implementation.
- **Superseded:** Replaced by another ADR; retain the record and link its
  replacement.
- **Deprecated:** No longer recommended but not yet replaced.

An ADR contains context, decision, consequences, alternatives, and implementation
evidence. Existing accepted decisions may be documented retrospectively when the
record prevents drift across new tickets.
